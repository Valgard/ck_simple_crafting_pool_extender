[h1]Simple Crafting Pool Extender[/h1]

A small helper mod for other mods. It lets mods add a 4th crafting tab — and beyond — to vanilla Simple-Crafting workbenches (the Iron, Wood and Copper Workbenches, Carpenter's Table, Forge and other stations), so their items actually appear in the crafting UI instead of being silently dropped.

[b]Do you need this?[/b] Only if another mod you use lists it as a dependency. On its own it adds nothing you can see — it's plumbing that other mods rely on. If a mod requires it, Steam and mod.io will prompt you to install both.

[b]What it fixes.[/b] Vanilla workbenches have room for exactly 3 crafting tabs. When a mod adds a craftable that needs a 4th, the game runs out of tab slots and the recipe never shows up. This mod raises the limit to 5 tabs and fixes the navigation-arrow position so the extra tabs page correctly.

[b]Safe for vanilla.[/b] Workbenches using only 1–3 tabs are completely unchanged, and unused tab slots cost nothing — the game hides them exactly as it always has.

[b]Multiplayer:[/b] this mod has no server-side behaviour of its own, but the workbench UI it patches renders on the client — install it wherever the mod that needs it is installed, matching that mod's own client/server requirements.

[h2]For mod authors[/h2]

Adding an item to a vanilla workbench? List Simple Crafting Pool Extender as a required dependency in your ModBuilderSettings, and mod.io/Steam will prompt players to install both. Without it, your recipe registers but never renders for players who don't already have a pool-expanding mod.
